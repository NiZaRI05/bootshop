¿Qué es Bootstrap?

Bootstrap es un **framework de código abierto** desarrollado originalmente por Twitter en 2011. Está diseñado para simplificar el desarrollo de páginas web front-end mediante HTML, CSS y JavaScript.

¡Dato clave! Su enfoque principal es el **Mobile-First** (diseño pensado primero para teléfonos móviles y luego adaptado a pantallas grandes).

¿Cómo se agrega a un sitio web?

Existen dos métodos principales para integrar Bootstrap en cualquier proyecto web:

  • 1. Vía CDN (Content Delivery Network): Copiando los enlaces de CSS y JS directamente en el HTML (usado en este proyecto).
  • 2. Instalación local: Descargando los archivos compilados o instalándolo mediante gestores de paquetes como npm install bootstrap.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/.../bootstrap.min.css" rel="stylesheet">

Principales Elementos de Bootstrap

El ecosistema de Bootstrap se divide en utilidades de diseño, grillas y componentes interactivos listos para usar:

Diseño y Rejilla

Contenedores, sistema de filas (row) y columnas (col) basados en Flexbox que permiten adaptar la web a cualquier pantalla.

Componentes Comunes

Botones, formularios estructurados, barras de navegación, alertas, grupos de listas y tarjetas de contenido.

Interactividad (JS)

Modales dinámicos, menús desplegables (dropdowns), carruseles de imágenes y efectos colapsables.
