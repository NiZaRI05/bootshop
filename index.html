¿Qué es Bootstrap?

Bootstrap es un framework de desarrollo web de código abierto muy popular, originalmente creado por Twitter. Se utiliza para diseñar y personalizar sitios web responsivos y adaptables a dispositivos móviles de manera rápida y eficiente.

Proporciona una colección extensa de herramientas basadas en HTML, CSS y JavaScript que permiten estructurar layouts complejos, añadir estilos tipográficos, botones, formularios y una gran variedad de componentes interactivos listos para usar.

¿Cómo se agrega a un sitio web?

Existen dos métodos principales para integrar Bootstrap en un proyecto web:

Método 1: Vía CDN (Recomendado para prácticas)

Consiste en enlazar los archivos CSS y JS directamente desde los servidores de Bootstrap copiando los enlaces dentro de las etiquetas <head> y al final del <body>. Es el método que utiliza esta página.

Método 2: Descarga Local o Gestores de Paquetes

Puedes descargar los archivos compilados de producción e incluirlos localmente en las carpetas de tu proyecto, o bien instalarlos utilizando herramientas profesionales como npm o yarn.

Principales elementos de Bootstrap

Bootstrap ofrece una enorme cantidad de utilidades y elementos listos para producción. A continuación, exploramos los fundamentales mediante una estructura de consulta interactiva:

Punto 1
El Sistema de Grid (Rejilla)

Es la base de todo el diseño responsivo. Se compone de un sistema de 12 columnas flexibles basados en Flexbox utilizando las clases .container, .row, y .col-*.

Punto 2
Componentes Comunes de IU

Elementos interactivos pre-estilizados listos para su uso directo, tales como:

Botones y Alertas: Estados visuales inmediatos para el usuario.
Modales y Tooltips: Ventanas emergentes e información contextual interactiva.
Formularios dinámicos: Controles adaptables e inputs limpios.
Punto 3
Clases de Utilidad de Bootstrap

Herramientas rápidas para modificar estilos sin escribir CSS personalizado adicional:

¡Tip de diseño! Bootstrap cuenta con utilidades de espaciado (Margen m-*, Padding p-*), alineación de textos, sombras, opacidad, y visibilidad de elementos según el tamaño de la pantalla.
